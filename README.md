# Eternal Nightmare

Eternal Nightmare is a realistic Roblox horror game featuring an advanced weapon system, a Developer Admin Panel, and a customized Infinite-Ammo Minigun. This project combines atmospheric tweaks with modular Lua scripting to create an immersive and engaging horror experience. The game includes a comprehensive admin panel for developers, allowing for easy management of the game environment and player interactions. The advanced weapon system provides a variety of weapons, including a powerful Infinite-Ammo Minigun, to enhance the gameplay experience.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the downloaded scripts in the appropriate locations within your Roblox Studio project.
5. Configure the scripts as needed for your game.

## Use

1. Initialize the Developer Admin Panel by calling the `Initialize` function from the `DeveloperAdminPanel.lua` script.
2. Use the admin panel to manage players and the game environment by calling the `HandleCommand` function with the appropriate command and player.
3. Initialize the atmospheric tweaks by calling the `Initialize` function from the `AtmosphericTweaks.lua` script.
4. Apply atmospheric effects by calling the `ApplyEffects` function from the `AtmosphericTweaks.lua` script.
5. Initialize the modular scripts by calling the `Initialize` function from the `ModularScripts.lua` script.
6. Load specific modules by calling the `LoadModule` function with the module name from the `ModularScripts.lua` script.
7. Initialize the advanced weapon system by calling the `Initialize` function from the `AdvancedWeaponSystem.lua` script.
8. Handle weapon firing by calling the `FireWeapon` function with the weapon type and player from the `AdvancedWeaponSystem.lua` script.
9. Initialize the Infinite-Ammo Minigun by calling the `Initialize` function from the `InfiniteAmmoMinigun.lua` script.
10. Handle minigun firing by calling the `Fire` function with the player from the `InfiniteAmmoMinigun.lua` script.
